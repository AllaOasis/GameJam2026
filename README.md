# ToxicorpFive

## How to Run

### Windows
1. Open the `Build` folder.
2. Run `ToxicorpFive-Windows.exe`.

### Linux
1. Open the `Build` folder.
2. Run `ToxicorpFive-Linux.x86_64`.
3. If needed, give the file permission to execute.
